# Univ 3 Fintech

منصة تعليمية بسيطة لفهم تقييم المخاطر الائتمانية للأفراد والشركات باستخدام الذكاء الاصطناعي.
مبنية بـ Python وStreamlit، بواجهة عربية من اليمين إلى اليسار.

> جميع البيانات **اصطناعية بالكامل** ومخصصة للتعلم والتجربة فقط.

---

## التثبيت والتشغيل

تحتاج **Python 3.10 أو أحدث**.

### 1. افتح الطرفية داخل مجلد المشروع

```bash
cd univ3_fintech
```

### 2. أنشئ بيئة افتراضية (مستحسن)

**لماذا؟** حتى تبقى مكتبات المشروع منفصلة عن باقي جهازك.

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. ثبّت المتطلبات

```bash
pip install -r requirements.txt
```

### 4. شغّل التطبيق

```bash
streamlit run app.py
```

يفتح المتصفح تلقائيًا على `http://localhost:8501`.

### 5. سجّل الدخول

| | |
|---|---|
| اسم المستخدم | `univ3` |
| كلمة المرور | `fintech2026` |

**غيّر كلمة المرور** قبل عرض المشروع:

```bash
python set_password.py
```

## ماذا يحدث عند أول تشغيل؟

1. لا يوجد ملف `univ3_fintech.db`، فيولّد التطبيق 800 فرد و200 شركة ويحفظهم فيه.
2. يدرّب النماذج الأربعة للأفراد، ثم الأربعة للشركات (بضع ثوانٍ).
3. في كل تشغيل لاحق تُقرأ البيانات نفسها من الملف.

لإنشاء بيانات جديدة: الصفحة الرئيسية ← «إعادة إنشاء البيانات الاصطناعية»، أو احذف ملف `univ3_fintech.db`.

## قرارات تقنية مهمة

- **تعريف التعثر:** تأخر 90 يومًا أو أكثر خلال 12 شهرًا بعد منح القرض (العمود `default_12m`).
- **لا تسرّب للمعلومات:** متغيرات التنبؤ كلها معروفة يوم تقديم الطلب. المعرّف وحالة التعثر لا يدخلان النموذج.
- **فصل التدريب عن الاختبار:** 75% تدريب / 25% اختبار للأفراد، و70% / 30% للشركات، مع الحفاظ على نسبة المتعثرين (`stratify`). الاختبار لا يُستعمل أبدًا في التدريب.
- **نماذج مستقلة:** الأفراد والشركات لكل منهم نماذجه الأربعة.
- **معالجة المتغيرات:** توحيد المقاييس (`StandardScaler`) للانحدار اللوجستي والشبكة العصبية، وتحويل الفئات إلى أعمدة 0/1 (`OneHotEncoder`). الأشجار تستعمل القيم الأصلية لتبقى شروطها مقروءة.
- **كلمة المرور:** PBKDF2-SHA256 مع ملح عشوائي و200 000 تكرار، و5 محاولات خاطئة توقف الدخول دقيقة.
- **التفسير:** لكل سجل ولكل نموذج نستبدل كل مؤشر بقيمته النموذجية ونقيس تغيّر الاحتمال، إضافة إلى المسار الفعلي داخل شجرة القرار ومساهمات الانحدار اللوجستي.

## النماذج

| النموذج | المكتبة | الإعدادات |
|---|---|---|
| الانحدار اللوجستي | `LogisticRegression` | افتراضية |
| شجرة القرار | `DecisionTreeClassifier` | عمق أقصى 4 |
| الغابة العشوائية | `RandomForestClassifier` | 200 شجرة، عمق أقصى 6 |
| الشبكة العصبية | `MLPClassifier` | طبقة خفية من 8 خلايا، alpha = 3 |

## حدود المشروع

- البيانات اصطناعية: النتائج توضّح المنهج ولا تصلح لقرارات إقراض حقيقية.
- عدد الشركات صغير (200)، فمقاييس الأداء للشركات أقل استقرارًا.
- تسجيل الدخول مناسب لمشروع جامعي على جهاز واحد، وليس نظام حماية لمؤسسة مالية.
